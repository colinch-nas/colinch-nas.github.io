운영 중인 NAS의 RAID·SHR·ZFS 풀에는 CMR 하드디스크를 우선 고르는 편이 안전하다. SMR은 순차 기록 위주의 단일 디스크 보관이나 오프라인 백업이면 비용을 줄일 수 있지만, 디스크 장애 뒤 재구축이 필요한 풀에 넣을 때는 느린 기록이 복구 시간을 늘릴 수 있다. CMR·SMR은 SATA나 용량만 보고는 알 수 없으므로 정확한 모델 번호를 확인해야 한다.

## CMR과 SMR을 용도별로 나누기

CMR은 기존 트랙을 겹치지 않게 기록하고, SMR은 트랙을 겹쳐 용량 밀도를 높인다. SMR이 항상 고장 난다는 뜻은 아니지만, 작은 쓰기가 반복되거나 기존 데이터를 다시 정렬해야 하는 작업에는 불리하다. Seagate도 SMR은 순차적이거나 쉽게 순차화할 수 있는 저장소에 적합하다고 설명한다.

| 용도 | 선택 | 이유 |
|---|---|---|
| Synology SHR·RAID 1/5/6 운영 풀 | CMR | 장애 후 재구축과 상시 쓰기를 고려 |
| TrueNAS ZFS RAIDZ | CMR 우선 | 리실버와 검증 작업의 변동을 줄임 |
| 단일 디스크 영화 보관 | SMR도 가능 | 쓰기가 끝난 뒤 읽기가 대부분인 경우 |
| 월 1회 연결하는 외장 백업 | SMR도 가능 | 순차 백업 위주, 복구 시간은 감수해야 함 |

SMR 두 개가 싸다고 기존 CMR 풀에 한 개씩 섞어 넣는 식으로 계산하면 안 된다. 제조사와 NAS 운영체제가 해당 모델을 지원하는지, 같은 풀에서 혼합했을 때 성능과 복구 절차가 어떤지 먼저 확인한다. Synology는 모델·DSM 버전별 드라이브 호환 목록을 제공하므로 제품명보다 전체 모델 번호를 검색해야 한다.

## 가격보다 복구 시간을 계산한다

가상 사례로 4베이 NAS에 12TB HDD 4개를 넣는다고 하자. CMR 한 개가 16만 원, SMR 한 개가 12만 원이라고 가정하면 처음 살 때 차이는 16만 원이다. 하지만 운영 풀에서 장애가 나면 디스크 교체, 백업 검증, 복구 중 성능 저하, 예비 디스크 보관 비용이 추가된다.

```text
3년 저장장치 비용 = 운영 풀 디스크
                  + 외장/원격 백업 디스크
                  + 예비 디스크 또는 교체 배송비
                  + 복구 중 작업 시간 비용
```

실제 가격이 아닌 계산 가정으로, CMR 운영 풀 64만 원과 SMR 운영 풀 48만 원, 별도 백업 디스크 16만 원, 예비 디스크 16만 원을 비교하면 총액은 각각 96만 원과 80만 원이다. SMR 쪽의 16만 원 절약이 복구 지연을 감수할 만큼 큰지 판단해야 한다. 전기료보다 장애 때의 복구 가능성과 시간이 구매 결정에 더 크게 작용하는 환경도 많다.

## 구매 전 체크리스트

- [ ] 제품 페이지가 아니라 전체 모델 번호로 CMR·SMR 방식을 확인했는가
- [ ] NAS 제조사의 호환 목록에서 모델·용량·DSM/OS 조건을 확인했는가
- [ ] 운영 RAID에는 CMR, 단일 보관·콜드 백업에는 SMR을 분리했는가
- [ ] RAID가 백업이 아니라는 전제로 다른 장치에 복사했는가
- [ ] 장애 시 교체할 같은 용량 이상의 디스크와 복원 순서를 준비했는가
- [ ] SMART 장기 테스트와 스크럽 시간을 업무가 적은 시간에 배정했는가

결국 “SMR은 NAS에서 절대 금지”보다 용도를 나누는 판단이 정확하다. 계속 쓰고, 여러 디스크를 재구축하고, 빠른 복구가 필요한 운영 풀은 CMR이 맞다. 한 번 기록하고 자주 읽지 않는 단일 디스크 백업이라면 SMR을 고려할 수 있지만, 백업 복원 시간이 길어질 수 있다는 조건을 비용표에 남겨야 한다.
