그림에서 볼 부분은 디스크 개수만 늘리는 게 아니라 RAM과 서비스 수까지 함께 커진다는 점이다.

TrueNAS SCALE 25.10을 파일 공유용으로 2베이에서 1~2명이 쓴다면 8GB를 유지해도 된다. 반대로 4베이에서 Docker 앱과 여러 SMB 사용자를 함께 운영하면 16GB가 구매 기준이 되고, VM·iSCSI·대용량 풀이 겹치면 32GB 이상을 검토한다. ECC는 필수 라이선스가 아니라 메모리 오류를 줄이는 방어 계층이다. 메인보드와 CPU가 ECC를 지원하지 않는다면 RAM만 ECC로 바꾸어도 효과가 생기지 않는다. 이 글의 가격은 실제 판매가가 아닌 비교용 가상 금액이다.

## 사용자 규모별 RAM 선택

TrueNAS 공식 하드웨어 가이드는 기본 작업과 최대 8개 드라이브에 8GB를 제시하고, 8개를 넘는 드라이브에는 드라이브당 1GB를 더하는 기준을 설명한다. 클라이언트 수, 앱, VM, iSCSI가 늘면 별도 RAM도 필요하다. 따라서 “ZFS는 RAM을 많이 먹으니 무조건 32GB”라는 식으로 사면 안 된다.

| 환경 | RAM 판단 | ECC 판단 | 구매하지 않아도 되는 조건 |
|---|---:|---|---|
| 2베이·1~2명·SMB와 백업 | 8GB | 지원 보드면 선택 | 앱·VM이 없고 메모리 부족 경고가 없음 |
| 4베이·2~4명·Docker 3~6개 | 16GB | 가능하면 ECC | 컨테이너를 거의 실행하지 않으면 8GB 유지 |
| 6~8베이·VM·iSCSI·다수 앱 | 32GB 이상 | ECC 우선 검토 | VM과 dedup을 쓰지 않으면 32GB를 미룰 수 있음 |

TrueNAS는 deduplication에 TB당 약 5GB RAM을 제안한다. 이 기능을 켤 계획이라면 32GB를 사는 문제가 아니라 실제 데이터 용량과 RAM 예산을 다시 계산해야 한다. L2ARC도 RAM을 사용하므로 SSD 캐시를 추가할 때 RAM을 전부 서비스에 배정하면 안 된다.

## 호환성은 용량보다 플랫폼이 먼저다

구매 전에는 메인보드의 DDR 세대, UDIMM/RDIMM 구분, 최대 용량, 슬롯별 제한, ECC unbuffered 지원 여부를 확인한다. 같은 DDR4라도 서버용 RDIMM과 일반 UDIMM은 함께 꽂을 수 없는 경우가 많다. 기존 모듈과 새 모듈을 섞을 때 클럭이 낮아지거나 부팅 자체가 실패할 수 있어, 가능하면 같은 용량·규격의 한 쌍으로 교체한다.

ECC를 선택할 때도 “ECC 표기”만 보지 않는다. CPU 메모리 컨트롤러, 메인보드 BIOS, 운영체제에서 ECC 오류를 읽는 경로가 모두 맞아야 한다. TrueNAS 공식 문서는 ECC를 강하게 권장하지만 모든 시스템이 ECC를 요구한다고 말하지 않으며, 어떤 RAM이든 고장 날 수 있으니 배포 전 테스트가 필요하다고 설명한다. 직접 확인하지 않은 조합은 호환된다고 단정하지 않는다.

## 가상 총비용으로 구매를 미룰지 계산한다

가상 예시로 기존 8GB를 0원, 16GB 키트를 7만 원, 32GB ECC 키트를 18만 원, 별도 복구용 HDD를 15만 원으로 잡아 보자. 2베이 파일 공유 NAS라면 32GB ECC보다 복구용 HDD가 먼저다. RAM이 부족해 앱이 종료되는 환경이라면 16GB와 백업 HDD를 합쳐 22만 원을 쓰는 쪽이 32GB만 사는 것보다 운영 위험을 줄인다.

| 선택 | 초기 추가비 | 해결하는 문제 | 해결하지 못하는 문제 |
|---|---:|---|---|
| 8GB 유지 | 0원 | 기본 SMB·백업 | VM 동시 실행, RAM 부족 |
| 16GB 일반/호환 RAM | 7만 원 | 앱과 사용자 증가 | 메인보드가 지원하지 않는 ECC |
| 32GB ECC 구성 | 18만 원 | VM·캐시·서비스 여유 | 삭제, 랜섬웨어, 디스크 고장 |
| 복구용 HDD 추가 | 15만 원 | 데이터 복원 경로 | RAM 부족과 보드 호환성 |

RAM은 백업이 아니다. TrueNAS 25.10 문서도 설정 파일을 저장하고, 부트 환경을 만들며, 데이터 백업을 별도로 구성하라고 안내한다. RAM 업그레이드 뒤에는 설정 백업을 새로 저장하고, 테스트 데이터셋을 만들어 앱 시작·SMB 복사·스크럽·복원 파일 열기를 확인한다.

## 구매 전 체크리스트

- [ ] CPU와 메인보드가 ECC UDIMM을 함께 지원하는가
- [ ] DDR 세대, 슬롯 수, 최대 용량, BIOS 제한을 확인했는가
- [ ] 현재 풀의 디스크 수와 사용자 수에 8·16·32GB 중 근거가 있는가
- [ ] VM·iSCSI·dedup·L2ARC를 실제로 사용할 계획인가
- [ ] RAM보다 외장 또는 원격 백업이 먼저 필요한 상태는 아닌가
- [ ] 업그레이드 후 설정 파일과 복원 테스트를 남길 수 있는가

짧게 판단하면, 8GB에서 메모리 부족 증상이 없는 2베이는 RAM을 사지 않아도 된다. 4베이 Docker 홈랩은 16GB부터 계산하고, VM·iSCSI·dedup이 겹치는 TrueNAS SCALE 25.10은 32GB와 ECC 지원 여부를 함께 본다. 어떤 용량을 고르든 백업 HDD와 복원 검증 예산을 빼고 RAM만 늘리는 선택은 피하는 편이 안전하다.
