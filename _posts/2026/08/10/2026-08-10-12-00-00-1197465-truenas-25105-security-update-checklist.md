TrueNAS Community Edition 25.10.x를 쓰고 있다면 2026년 7월 24일 공개된 **25.10.5**로 올리는 편이 낫다. Linux 커널 6.12.95로 바뀌면서 SharedFrag(CVE-2026-43503), PeditCOW(CVE-2026-46331) 같은 로컬 권한 상승 취약점이 수정됐고, SMART 상태가 잘못 표시되던 문제와 TrueCloud Backup 작업 중단 문제도 고쳐졌다. 내 홈서버 기준으로는 기능 추가보다 이 업데이트의 목적이 “데이터를 지키는 패치”에 가깝다.

## 25.10.5에서 달라진 점

| 항목 | 실제 영향 |
|---|---|
| Linux 커널 | 보안 취약점 8건과 상위 프로젝트 수정 반영 |
| SMART | 일부 디스크 건강 상태를 잘못 읽던 파싱 오류 수정 |
| TrueCloud Backup | restic 오류 뒤 작업이 멈추던 현상 수정 |
| SSH 키 | 복제·클라우드 자격 증명 처리 강화 |
| 공유 권한 | 특정 상황에서 ACL 편집이 막히던 문제 수정 |

다만 **TrueNAS 26-BETA.2**와는 구분해야 한다. 26은 OpenZFS 2.4, LXC 컨테이너 같은 변화가 들어간 테스트 버전이고, 공식 안내도 Early Adopter에게만 권장한다. 사진과 백업이 들어 있는 일반 NAS라면 지금은 25.10.5가 맞다.

## 업데이트 전 10분 점검

업데이트 버튼부터 누르면 재부팅 뒤 문제가 생겼을 때 원인을 찾기 어렵다. 아래 네 가지를 먼저 확인했다.

| 점검 | 통과 기준 |
|---|---|
| 설정 백업 | System Settings → General → Manage Configuration에서 파일 다운로드 |
| 풀 상태 | Storage → Dashboard에서 `ONLINE`, 디스크 오류 0건 |
| 스크럽·리실버 | 진행 중인 작업이 없고 마지막 결과가 정상 |
| 공유 서비스 | SMB, NFS, 앱 컨테이너를 잠시 중지할 수 있음 |

설정 백업은 데이터 백업과 다르다. 설정 파일만 복구해도 디스크가 고장 난 뒤의 사진과 문서가 살아나는 것은 아니다. 최소한 중요한 데이터는 다른 디스크나 외장 저장장치에 한 번 더 복사해야 한다.

## 웹 화면에서 25.10.5 설치

TrueNAS 관리 화면에서 **System Settings → Update → Check for Updates**를 선택한다. 25.10.5가 보이면 릴리스 노트를 확인하고, 자동 재부팅과 서비스 중지 안내에 동의한 뒤 설치한다. 업데이트 중에는 전원을 끄지 않는다. 미니PC 홈서버라면 UPS(무정전 전원장치)가 없을 때 정전 가능성이 낮은 시간에 진행하는 게 안전하다.

재부팅 후에는 버전만 보지 말고 실제 서비스를 확인한다. 콘솔이나 SSH에서 다음 명령으로 풀과 부팅 환경을 점검할 수 있다.

```bash
# ZFS 풀의 온라인 상태와 디스크 오류를 확인한다.
zpool status

# 현재 TrueNAS 버전을 확인한다.
sudo midclt call system.version
```

출력에 풀 상태가 `ONLINE`인지, `DEGRADED`나 `FAULTED`가 없는지 본다. 그 다음 SMB 공유에서 파일을 열고 저장하고, Docker 앱이 있다면 컨테이너 로그에 반복적인 오류가 없는지 확인한다. SMART 화면의 온도·오류 카운터도 업데이트 전 기록과 비교하면 이번 패치 효과를 확인하기 쉽다.

## 여기서 자주 하는 실수

업데이트 직후 풀에서 “업그레이드” 버튼이 보여도 성급하게 누르지 않는 게 좋다. 시스템 업데이트와 ZFS 풀 기능 업그레이드는 다른 작업이다. 특히 26 베타를 시험할 때 풀까지 업그레이드하면 이전 부트 환경으로 돌아가도 새 기능을 모르는 버전에서 풀을 열지 못할 수 있다. 먼저 시스템만 바꾸고, 복귀 가능성을 확인한 뒤 풀 변경을 판단해야 한다.

또한 업데이트 후 SMART 경고가 새로 보였다고 해서 바로 디스크를 교체하지는 말자. 25.10.5에서 파싱 오류가 수정됐기 때문에 기존에 잘못 읽던 값이 정상화됐을 가능성도 있다. `zpool status`, 디스크 SMART 상세 화면, 최근 백업 성공 여부를 함께 보고 판단하는 편이 정확하다.

## 짧게 정리

TrueNAS 25.10.5는 새 기능을 시험하는 버전이 아니라 커널 보안과 운영 오류를 줄이는 안정 업데이트다. 설정 파일을 먼저 내려받고, 풀 상태가 `ONLINE`인지 확인한 뒤 웹 UI에서 설치한다. 재부팅 후에는 SMB 파일 접근·앱·SMART·백업을 직접 한 번씩 확인하고, TrueNAS 26 베타와 풀 업그레이드는 별도 실험 환경에서 진행하는 게 안전하다.
