![TrueNAS 홈서버 보안 업데이트](https://images.unsplash.com/photo-1558494949-ef010cbdcc31?w=1200&q=80)

TrueNAS 25.10.5는 2026년 8월 15일 기준 안정 버전 유지보수 릴리스다. 26-BETA.3도 공개됐지만 사진·문서가 있는 홈서버라면 25.10 계열을 적용하는 편이 맞다. 업데이트 전 설정 파일과 스냅샷을 남기면 복구 지점을 확보할 수 있다.

## 버전 선택과 환경

25.10.5는 보안 취약점 대응을 포함한다. 26-BETA.3는 테스트 목적의 초기 버전이므로 운영 풀에는 올리지 않는다.

| 버전 | 적용 기준 |
|---|---|
| TrueNAS 25.10.5 | 운영 데이터가 있는 홈서버 |
| TrueNAS 26-BETA.3 | 별도 디스크의 테스트 풀 |

## 업데이트 전 점검

웹 UI에서 **System Settings → General → Manage Configuration → Download File**을 눌러 설정 파일을 저장한다. 계정·네트워크·공유 설정 복원용이므로 NAS 밖의 PC나 암호화된 USB에도 복사한다.

데이터셋은 **Datasets → 해당 풀 → Snapshots**에서 `before-25105-update-20260826`처럼 수동 스냅샷을 만든다. 스냅샷은 같은 풀 안의 복구 지점이므로 외장 디스크 백업을 대신하지 않는다.

아래 작업도 잠시 멈춘다.

- SMB 복사, Scrub, Replication
- 실행 중인 Apps 컨테이너와 VM
- UPS(무정전 전원 장치)와 암호화된 풀의 복구 키 확인

## TrueNAS 25.10.5 적용

이제 **System Settings → System → Update**에서 업데이트 확인을 실행한다. 자동으로 보이지 않으면 공식 다운로드 페이지에서 파일을 받고 SHA256 해시를 비교한다. 출처가 불명확한 이미지 파일은 사용하지 않는다.

업데이트하면 재부팅된다. 웹 UI가 끊겼다고 전원을 강제로 끄지 말고, 콘솔에서 부팅이 끝날 때까지 기다린다.

```text
System Settings → System → Update
→ Check for Updates → TrueNAS 25.10.5 선택
→ Confirm → Reboot 후 대기
```

## 재부팅 후 확인표

버전 숫자만 확인하고 끝내면 앱이나 공유 서비스의 오류를 놓칠 수 있다.

| 대상 | 확인 방법 |
|---|---|
| 버전 | System Settings → General에서 25.10.5 확인 |
| 풀 | Storage에서 `ONLINE`, 오류 카운터 증가 여부 확인 |
| SMB | 다른 PC에서 파일 읽기·쓰기 테스트 |
| 앱·VM | Apps와 Virtual Machines에서 Running 확인 |
| 백업 | Replication·Cloud Sync 마지막 성공 시간 확인 |

USB 동글, GPU 패스스루, VM 브리지는 업데이트 뒤 장치 경로와 권한을 따로 본다. 정상일 때 중지했던 작업을 다시 켠다.

부팅 실패가 생기면 **System Settings → System → Boot**에서 이전 부트 환경을 선택할 수 있다. 이 기능은 시스템 부팅 환경을 되돌리는 방법이지, 삭제된 파일을 복구하는 기능은 아니다. 파일 복구까지 필요하다면 별도 백업이 있어야 한다.

운영 홈서버는 25.10.5로 패치하고, 설정 파일·스냅샷·외부 백업을 남긴 뒤 SMB와 앱을 확인하면 된다. 26-BETA.3는 테스트 환경에서만 다룬다.
