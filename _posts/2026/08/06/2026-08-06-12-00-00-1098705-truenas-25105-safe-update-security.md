TrueNAS Community Edition을 운영 중이라면 25.10.5 업데이트를 미루기보다 백업을 확인한 뒤 적용하는 편이 낫다. 2026년 7월 24일 공개된 25.10.5에는 Linux kernel 6.12.95와 여러 보안 수정이 포함됐고, `CVE-2026-43503`, `CVE-2026-46331` 같은 로컬 권한 상승 취약점도 패치됐다. 다만 TrueNAS 26 베타와는 별개인 25.10 안정 계열 업데이트다.

이 그림에서 볼 부분은 업데이트 버튼보다 재부팅 뒤 서비스 상태를 확인할 준비가 되어 있는지다.

## 적용 전 환경과 확인표

이번 점검 기준은 TrueNAS SCALE 25.10.x, ZFS 데이터 풀 1개, SMB 공유와 Docker 앱을 함께 쓰는 미니 PC 홈서버다. VM이나 iSCSI가 없으면 점검 시간이 짧아진다.

| 항목 | 업데이트 전 확인 | 이유 |
|---|---|---|
| 설정 | System Settings → General → Manage Configuration에서 설정 파일 저장 | 네트워크·공유·계정 복구용 |
| 데이터 | 최근 스냅샷과 원격 복제 성공 여부 | 업데이트는 백업을 대신하지 않음 |
| 서비스 | SMB 복사와 앱 작업 종료 | 재부팅 중 파일·DB 쓰기 방지 |
| 부팅 | 부트 풀 여유 공간과 현재 부트 환경 확인 | 실패 시 이전 환경으로 되돌릴 여지 확보 |

설정 파일은 데이터 백업과 다르다. 사진과 문서가 다른 디스크나 클라우드에 복제되어 있는지까지 확인해야 한다. 스냅샷만 있고 실제로 다른 장비에서 읽어본 적이 없다면 복구 준비가 끝난 것으로 보지 않았다.

## TrueNAS 25.10.5 업데이트 순서

웹 화면에서 `System Settings → System → Update`로 이동해 현재 버전을 확인한다. 새 버전이 보이면 릴리스 노트의 재부팅 여부와 앱 호환성 공지를 읽은 뒤 업데이트 파일을 다운로드한다. 원격 접속만 가능한 NAS라면 전원 장애나 재부팅 중 네트워크 단절에 대비해 같은 LAN의 관리 PC를 남겨두는 게 안전하다.

업데이트 직전에는 SMB 복사, Docker 앱, VM을 순서대로 멈춘다. 특히 Immich처럼 데이터베이스를 쓰는 앱은 컨테이너만 끄지 말고 작업이 끝났는지 로그에서 확인한다. SSH를 켜둔 서버라면 업데이트 후에도 키 로그인과 고정 IP가 유지되는지 확인할 수 있도록 현재 설정을 메모해 둔다.

콘솔이나 SSH에서 풀 상태를 확인할 때는 이 명령을 사용한다.

```bash
zpool status
zfs list
```

`zpool status`에 `DEGRADED`나 `FAULTED`가 표시되면 업데이트보다 디스크 상태와 백업을 먼저 처리한다. 풀에 문제가 있는 상태에서 재부팅 변수를 추가하면 원인 분리가 어려워진다.

## 재부팅 후 검증할 순서

관리 화면에 다시 접속한 뒤 대시보드의 Alert를 지우는 데 집중하지 말고 실제 동작을 확인한다. NAS IP와 DNS가 그대로인지, 풀 상태가 `ONLINE`인지, SMB 공유에 새 파일을 만들고 다시 읽을 수 있는지 순서대로 테스트한다. 이후 앱을 하나씩 올려 사진 업로드나 미디어 스캔처럼 실제 작업을 짧게 실행한다.

| 검증 대상 | 통과 기준 |
|---|---|
| ZFS 풀 | 모든 디스크가 `ONLINE`, 오류 카운터 증가 없음 |
| SMB | Windows·macOS에서 읽기와 쓰기 성공 |
| Docker 앱 | 컨테이너가 재시작 반복 없이 `Up` 상태 |
| VM·iSCSI | 게스트 부팅과 마운트 경로 정상 |
| 알림 | 새 하드웨어·부트 풀·인증서 경고 없음 |

이번 업데이트에서 중요한 판단은 25.10.5를 설치한 뒤 곧바로 TrueNAS 26 베타로 넘어가지 않는 것이다. 보안 패치와 메이저 버전 전환은 별도 작업으로 잡아야 장애가 생겼을 때 되돌릴 수 있다. 공식 공지 기준 TrueNAS 25.10.5는 운영용 유지보수판이고, TrueNAS 26은 아직 Early Release 흐름에 있다.

짧게 정리하면 `설정 파일 저장 → 스냅샷·원격 백업 확인 → SMB·앱·VM 중지 → 25.10.5 업데이트 → 풀·공유·서비스 실사용 테스트` 순서다. 업데이트 버튼을 누르는 시간보다 재부팅 후 검증 시간을 넉넉히 잡는 것이 홈서버에서는 더 중요하다.
