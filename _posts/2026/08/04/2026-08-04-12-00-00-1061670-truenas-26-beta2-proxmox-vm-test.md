TrueNAS 26-BETA.2는 운영용 NAS에 바로 올릴 버전이 아니다. 2026년 8월 4일 기준 공식 소프트웨어 현황에서도 TrueNAS 26은 Early Release로 분류되고, 안정 버전은 TrueNAS 25.10.4다. 새 UI나 하드웨어 호환성을 확인하고 싶다면 Proxmox VE 9.2 VM에 임시 풀을 만들어 테스트하는 방식이 가장 덜 위험하다.

## 테스트 환경과 용량 기준

이번 테스트는 실제 디스크를 넘기지 않고 가상 디스크만 사용한다. VM을 지워도 원본 데이터에는 영향을 주지 않는 구성이 핵심이다.

| 항목 | 테스트 값 | 이유 |
|---|---:|---|
| Proxmox | VE 9.2 | 최근 홈랩 기준 |
| VM 메모리 | 16GB | ZFS 테스트용 여유 확보 |
| 부팅 디스크 | 32GB | TrueNAS 시스템 전용 |
| 데이터 디스크 | 100GB 2개 | 미러 풀과 SMB 검증 |
| 네트워크 | VirtIO, 브리지 | 실사용과 비슷한 연결 |

TrueNAS는 메모리를 많이 쓰는 편이라 8GB에서도 부팅은 되지만, 풀 생성과 앱 테스트를 함께 하면 금방 답답해진다. 기존 Proxmox VM이나 컨테이너가 있다면 메모리를 고정으로 예약하지 말고, 테스트 시간에만 16GB를 배정하는 편이 낫다.

## Proxmox에 TrueNAS 26-BETA.2 설치

공식 [TrueNAS 26 버전 노트](https://www.truenas.com/docs/scale/26/gettingstarted/versionnotes/)에서 `26-BETA.2` ISO를 받은 뒤 SHA256 해시를 확인한다. 베타 ISO를 검증하지 않고 설치한 적이 있는데, 다운로드 중 깨진 파일을 뒤늦게 발견해 VM을 다시 만들었다.

```bash
sha256sum TrueNAS-SCALE-26.0-BETA.2.iso
```

Proxmox에서 `Create VM`을 누르고 ISO를 연결한다. BIOS는 기본 SeaBIOS로 두고, 디스크는 `SCSI`보다 설치가 단순한 `VirtIO Block`을 사용해도 된다. 네트워크는 `vmbr0`, 모델은 `VirtIO (paravirtualized)`를 선택한다. 부팅 디스크와 데이터 디스크를 반드시 분리해야 한다.

설치 화면에서는 부팅 디스크만 선택하고 `Reboot`한다. 재부팅 뒤 ISO를 분리하지 않으면 설치 화면이 반복된다. 콘솔에 표시되는 IP로 웹 브라우저에 접속해 관리자 계정을 만들고, 지역·시간대를 `Asia/Seoul`로 맞춘다.

## ZFS 미러와 SMB 공유 확인

`Storage > Create Pool`에서 100GB 디스크 두 개를 선택하고 레이아웃을 `Mirror`로 지정한다. 이 풀은 성능 측정용이 아니라 장애 시 한 장이 남는 구성을 확인하기 위한 것이다. 베타 테스트 데이터만 저장하고, 기존 데이터셋을 가져오지 않는다.

`Datasets > Add Dataset`에서 `share`를 만들고 `Share Type`을 `SMB`로 지정한다. 이어서 `Credentials > Local Users`에서 일반 사용자를 만든 뒤 `Shares > Windows Shares (SMB)`에 `/mnt/testpool/share`를 등록한다. 관리자 계정으로 SMB를 쓰면 권한 문제를 찾기 어려워 일반 사용자로 접속하는 것이 좋다.

윈도우에서는 탐색기 주소창에 다음처럼 입력한다.

```text
\\192.168.1.250\share
```

파일 생성·삭제, 큰 파일 복사, VM 강제 종료 후 재부팅까지 확인한다. 스냅샷은 `Data Protection > Periodic Snapshot Tasks`에서 만들 수 있지만, 스냅샷은 백업이 아니다. 베타 UI를 검증하는 동안에도 중요한 파일은 실제 백업 장치에 따로 보관한다.

## 베타 버전에서 피할 설정

- 운영 ZFS 풀이나 디스크를 VM에 연결하지 않는다.
- TrueNAS 25.10에서 바로 업그레이드하지 않고 별도 VM에서 확인한다.
- 앱 카탈로그, SMB, 정전 후 부팅처럼 필요한 항목만 시험한다.
- 결과가 괜찮아도 정식 릴리스와 마이그레이션 경로가 확인되기 전에는 교체하지 않는다.

정리하면 TrueNAS 26-BETA.2는 새 기능을 구경하는 용도보다 하드웨어·네트워크·공유 호환성을 미리 확인하는 홈랩 재료에 가깝다. Proxmox VM에 부팅 디스크와 데이터 디스크를 나누고, ZFS 미러와 SMB 접속까지만 검증하면 운영 NAS를 건드리지 않고도 업그레이드 판단에 필요한 정보를 얻을 수 있다.
