QNAP이 2026년 7월 23일 TS-262A와 TS-462A를 출시했다. 둘 다 QTS 5.2, Intel Celeron N5095, 2.5GbE를 사용하고 M.2 NVMe 슬롯 2개가 있다. 2베이면 TS-262A, 사진·영상과 백업을 함께 둘 거면 TS-462A가 현실적인 선택이다. 처음 켰을 때 앱부터 설치하기보다 저장소와 관리자 보안을 먼저 잡아야 나중에 Docker나 QuMagie를 올려도 덜 꼬인다.

## 모델 선택과 준비물

QNAP 공식 사양상 두 모델 모두 기본 메모리는 4GB이고 최대 16GB까지 확장할 수 있다. 2.5GbE 포트는 2.5G/1G/100M에 대응하며, 3.5인치 HDD와 2.5인치 SSD를 핫스왑 방식으로 쓸 수 있다.

| 항목 | TS-262A | TS-462A |
|---|---:|---:|
| 드라이브 베이 | 2개 | 4개 |
| 추천 용도 | 문서·사진·개인 백업 | 미디어·가족 공유·장기 확장 |
| RAID 1 | 가능 | 가능 |
| 2.5GbE | 1개 | 1개 |
| NVMe | M.2 2280 2개 | M.2 2280 2개 |

하드디스크는 같은 용량 2개를 준비하고, NAS와 공유기는 Cat6 케이블로 연결했다. 노트북이 1GbE라면 NAS만 2.5GbE여도 속도가 올라가지 않는다. 이 부분을 모르고 NAS만 바꿨다가 파일 복사 속도가 그대로인 경우가 많다.

## QTS 5.2 초기 설정

전원을 켠 뒤 같은 네트워크의 PC에서 Qfinder Pro로 NAS를 찾는다. 브라우저로 표시된 IP에 접속해 QTS 설치를 시작한다. 자동 설치 중 펌웨어가 바뀔 수 있으므로 공유기와 NAS의 전원을 중간에 끄지 않는다.

설치 화면에서 다음처럼 정했다.

| 설정 | 선택 기준 |
|---|---|
| NAS 이름 | `qnap-home`처럼 용도를 표시 |
| 관리자 계정 | `admin`이 아닌 별도 이름 |
| 시간대 | Asia/Seoul, NTP 자동 동기화 |
| 업데이트 | 자동 설치 대신 알림 후 수동 적용 |
| 네트워크 | 우선 DHCP 예약, 이후 고정 IP |

초기 설치가 끝나면 **Control Panel → System → General Settings**에서 시간대를 확인한다. 시간이 틀리면 예약 백업과 로그 확인 시간이 모두 어긋난다. 관리자 계정에는 2단계 인증을 켜고, `admin` 계정은 비활성화한다. 비밀번호는 NAS에서만 쓰는 긴 문장으로 만들었다.

## Storage & Snapshots에서 RAID 만들기

**Storage & Snapshots → Storage/Snapshots → New Storage Pool**로 들어가 디스크를 선택한다. TS-262A는 두 디스크를 RAID 1로 묶는 구성이 기본이다. RAID 1은 같은 데이터를 두 디스크에 저장하는 미러링 방식이라 한 개가 고장 나도 서비스가 멈추지 않지만, usable capacity(실제 사용 가능 용량)는 디스크 하나 수준이다.

스토리지 풀을 만든 뒤 그 안에 thick volume을 생성했다. 컨테이너와 일반 파일을 같이 쓸 때 용량을 직접 관리하기 쉽다. **Snapshot**은 켜되, 스냅샷을 백업으로 착각하면 안 된다. 랜섬웨어가 공유 폴더를 암호화하면 접근 가능한 스냅샷까지 영향을 받을 수 있다.

## 2.5GbE와 공유 폴더

**Network & Virtual Switch → Interfaces**에서 현재 연결 속도를 확인한다. PC와 스위치가 모두 2.5GbE일 때만 2.5Gbps 링크가 잡힌다. 링크가 1Gbps로 표시되면 케이블보다 먼저 스위치 포트와 PC 랜카드 사양을 확인한다.

공유 폴더는 `home`, `media`, `backup`을 분리했다. 가족 파일과 Docker 설정을 한 폴더에 섞으면 권한을 나중에 고치기 어렵다. SMB 버전은 **Control Panel → Network & File Services → Win/Mac/NFS → Advanced Options**에서 SMB 2 이상으로 제한하고, 게스트 접근은 끈다.

## 외부 접속과 백업 체크

QNAP 장비를 설치하자마자 myQNAPcloud 링크나 포트 포워딩부터 켜지 않는다. 외부 접속이 필요하면 먼저 QVPN 또는 Tailscale처럼 VPN 방식으로 구성하고, 라우터에서 관리자 포트와 SSH 포트를 인터넷에 직접 공개하지 않는다.

HBS 3(Hybrid Backup Sync)는 **App Center**에서 설치한 뒤 `backup` 공유 폴더를 외장 USB 또는 다른 NAS로 복사하는 작업을 만든다. 적어도 주 1회 예약하고, 버전 관리와 암호화를 켠다.

체크리스트는 짧게 남겨두면 된다.

- 관리자 계정 이름 변경, 2단계 인증 완료
- RAID 초기 동기화가 끝난 뒤 파일 저장
- SMB 게스트 접근과 UPnP 비활성화
- QTS와 앱 업데이트 전 설정 백업
- HBS 3 복구 테스트로 실제 파일 하나 꺼내보기

TS-262A·TS-462A의 장점은 2.5GbE와 NVMe 확장을 처음부터 쓸 수 있다는 점이다. 반대로 RAID 1은 백업이 아니고, NVMe 캐시도 느린 HDD를 마법처럼 빠르게 만들지는 않는다. 저장소를 만든 뒤 보안 계정, 공유 권한, 다른 장치로의 백업까지 끝내야 NAS 초기 설정이 끝난다.
