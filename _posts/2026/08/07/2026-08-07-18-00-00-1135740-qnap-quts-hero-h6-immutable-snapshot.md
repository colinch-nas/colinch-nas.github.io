QNAP QuTS hero h6.0에서는 **Immutable Snapshots(보호 기간 동안 변경·삭제할 수 없는 스냅샷)**를 만들 수 있다. 오늘 확인한 QNAP 공식 발표 기준으로 h6.0 정식 버전은 2026년 5월 29일 공개됐고, 이 기능은 QuTS hero 모델 전체에서 제공된다. 파일을 암호화하는 랜섬웨어가 NAS 관리자 권한까지 가져가도 복구 지점을 남기는 것이 핵심이다.

다만 스냅샷은 백업 자체가 아니다. NAS가 고장 나거나 도난당하면 함께 사라진다. 내가 적용한 기준은 NAS 안에 짧은 복구 지점을 두고, USB 디스크나 다른 NAS에 별도 사본을 만드는 방식이다.

## 적용 환경

| 항목 | 기준 환경 |
|---|---|
| NAS OS | QuTS hero h6.0 Official |
| 저장소 | ZFS 스토리지 풀, 문서 데이터셋 |
| 네트워크 | 내부망 1GbE, 외부 SMB 포트 미공개 |
| 목적 | 문서·사진 폴더의 30일 복구 지점 |

QTS(ext4) 기반 모델에서는 이 글의 메뉴가 보이지 않는다. 먼저 **제어판 → 시스템 → 펌웨어 업데이트**에서 모델이 QuTS hero h6.0을 지원하는지 확인하고, 업데이트 전 설정 파일과 중요 데이터부터 별도 저장한다.

## Immutable Snapshot 만들기

QNAP 화면에서 **스토리지 및 스냅샷 → 스토리지/스냅샷 → 데이터셋**으로 들어간다. `documents`처럼 중요한 데이터셋을 선택한 뒤 **스냅샷 → 스냅샷 일정**을 연다.

내 설정은 아래처럼 잡았다.

| 설정 | 값 | 이유 |
|---|---:|---|
| 실행 주기 | 매시간 | 실수로 덮어쓴 파일 복구 |
| 보존 기간 | 30일 | 저장공간과 복구 범위의 균형 |
| 보호 기간 | 14일 | 관리자 계정 탈취 후 삭제 방지 |
| 보존 규칙 | 최근 720개 | 24시간 × 30일 |

스냅샷 생성 화면에서 **Immutable Snapshot** 또는 보호 기간 옵션을 켜고 14일을 입력한다. 보호 기간이 시작되면 해당 스냅샷은 일반 관리자 화면에서도 바로 삭제할 수 없다. 테스트할 때는 작은 `test` 데이터셋에서 먼저 1시간 주기로 확인하는 편이 안전하다.

```text
스토리지 및 스냅샷
  → 데이터셋 선택
  → 스냅샷
  → 스냅샷 일정
  → 매시간 / 30일 보존
  → Immutable Snapshot 보호 기간 14일
```

## 실제 복구 테스트

스냅샷을 만들었다고 복구가 끝난 것은 아니다. `documents/test.txt`를 만든 뒤 내용을 바꾸고, 데이터셋의 **스냅샷 목록 → 복구 지점 선택 → 스냅샷 탐색**으로 이전 파일을 확인한다. 운영 중인 데이터셋 전체를 즉시 되돌리기보다, 먼저 별도 공유 폴더로 파일 하나를 복원해 권한과 이름이 정상인지 확인했다.

이 과정에서 헷갈렸던 부분은 스냅샷 복구가 외부 백업 복원처럼 보이지 않는다는 점이다. 스냅샷은 같은 ZFS 풀의 블록을 바라보므로 빠르지만, 풀 자체가 손상되면 사용할 수 없다.

## 3-2-1 백업으로 마무리

스냅샷을 1차 복구 지점으로 두고 **HBS 3(Hybrid Backup Sync)**에서 외부 사본을 추가한다.

```text
원본: /share/documents
  → HBS 3 백업 작업
  → USB 디스크 또는 다른 NAS
  → 매일 03:00 실행
  → 버전 관리 30개
```

USB 디스크는 백업이 끝난 뒤 분리해 둔다. 항상 연결된 USB는 NAS 관리자 계정이 탈취됐을 때 같이 삭제될 수 있다. 외부 공유가 필요하다면 SMB 포트를 인터넷에 열지 말고 VPN으로 접속한다. 관리자 계정에는 MFA를 켜고, QuTS hero h6.0의 FIDO2 패스키도 지원되는 모델이라면 추가한다.

## 설정 전 체크리스트

- [ ] QuTS hero 모델과 h6.0 호환 여부 확인
- [ ] 스냅샷을 적용할 데이터셋을 문서·사진처럼 분리
- [ ] 보호 기간과 저장공간 사용량을 함께 계산
- [ ] USB 또는 다른 NAS에 별도 백업 생성
- [ ] 실제 파일 1개를 복원해 권한까지 확인
- [ ] 인터넷에 SMB·관리자 포트를 직접 공개하지 않기

QuTS hero h6.0의 불변 스냅샷은 랜섬웨어 복구 시간을 줄여주는 기능이지 RAID나 외부 백업을 대신하는 기능은 아니다. `매시간 스냅샷 + 30일 보존 + 14일 불변 보호 + 분리된 외부 백업` 정도로 시작하면 가정용 문서·사진 NAS에서도 과하지 않게 적용할 수 있다.
