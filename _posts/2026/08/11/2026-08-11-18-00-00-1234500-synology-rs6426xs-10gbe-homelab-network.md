그림에서 볼 것은 NAS의 크기보다 NAS와 스위치, 백업 장비가 분리되어 연결되는 구조다.

Synology가 2026년 6월 10일 RS6426xs+ RackStation을 공개했다. 이 제품을 홈랩에 들일 때 성능표만 보고 연결하면 10GbE가 있어도 체감 속도가 거의 없다. NAS와 스위치 사이만 빠르고 PC, 케이블, 공유 폴더가 1GbE 설정에 묶여 있기 때문이다. 아래는 RS6426xs+와 DSM 7.4, 10GbE 관리형 스위치, 2.5GbE PC를 기준으로 잡은 실제 배치 순서다.

## 먼저 정할 네트워크 구조

NAS를 공유기 바로 옆에 두고 모든 장치를 같은 대역에 넣는 구성은 처음엔 쉽다. 하지만 스마트홈 장치와 관리자 화면까지 같은 네트워크에 있으면 사고 범위가 커진다. 내 기준은 관리용·일반 파일용·IoT용을 나누는 방식이다.

| 구간 | 예시 대역 | 허용할 연결 |
|---|---|---|
| 관리 VLAN | 192.168.10.0/24 | 관리자 PC → DSM, 스위치 |
| 서버 VLAN | 192.168.20.0/24 | PC·Jellyfin → SMB·서비스 |
| IoT VLAN | 192.168.30.0/24 | Home Assistant → 필요한 장치 |
| 백업 대상 | 별도 디스크·서버 | NAS → 백업 장치 |

VLAN(하나의 물리망을 논리적으로 분리하는 기능)을 지원하지 않는 공유기라면 억지로 설정하지 말고, 우선 NAS 관리 포트를 일반 PC에서만 접근하도록 방화벽부터 적용한다. 라우터에서 NAS의 DSM 포트와 SSH 포트를 인터넷으로 포워딩하지 않는 것이 출발점이다.

## 10GbE 연결에서 놓치기 쉬운 부분

RS6426xs+의 고속 포트를 스위치에 꽂은 뒤에는 DSM의 `제어판 → 네트워크 → 네트워크 인터페이스`에서 링크 속도를 확인한다. 10Gbps로 표시되지 않으면 케이블이나 스위치 포트 협상이 먼저 의심 대상이다. PC가 2.5GbE라면 NAS만 10GbE여도 PC와 NAS 사이의 실제 상한은 2.5Gbps다.

SMB(Windows 파일 공유 프로토콜)는 공유 폴더별 권한을 따로 둔다. `media`는 읽기 중심, `documents`는 가족 계정별 쓰기 권한, `backup`은 백업 계정만 쓰기 가능하게 만든다. 관리자 계정으로 네트워크 드라이브를 연결하면 랜섬웨어가 관리자 권한을 그대로 물려받을 수 있다.

## DSM에서 바로 적용할 설정

`제어판 → 보안 → 방화벽`에서 관리 VLAN의 관리자 PC만 DSM·SSH에 접근하도록 규칙을 만든다. 서버 VLAN에는 SMB와 필요한 컨테이너 포트만 열고, IoT VLAN에서 DSM 관리 포트로 들어오는 규칙은 거부한다. 규칙은 위에서부터 적용되므로 허용 규칙을 거부 규칙보다 위에 둬야 한다.

`제어판 → 사용자 및 그룹`에서는 다음처럼 계정을 나눈다.

| 계정 | 용도 | 관리자 권한 |
|---|---|---|
| admin 개인 계정 | DSM 관리 | 필요할 때만 부여 |
| media-user | Jellyfin·SMB 읽기 | 없음 |
| backup-user | Hyper Backup 대상 | 없음 |

기본 `admin` 계정은 비활성화하고, 2단계 인증을 켠다. 외부 접속이 필요하면 포트포워딩보다 Tailscale VPN을 먼저 검토한다. Reverse Proxy(외부 도메인 요청을 내부 서비스로 전달하는 중계 서버)를 쓰더라도 DSM 자체를 인터넷에 공개할 이유는 없다.

## 속도보다 먼저 백업을 검증한다

새 NAS로 데이터를 옮기기 전에 `Hyper Backup`에서 설정 백업과 파일 백업을 각각 만든다. 스냅샷은 같은 NAS 안의 빠른 복구 수단이고, 다른 장치에 있는 백업을 대신하지 않는다. 최소한 아래 순서로 테스트한다.

1. 문서 파일 10개를 `backup-user`로 외부 백업한다.
2. 원본 공유 폴더에서 파일 1개를 지운다.
3. 백업 작업의 무결성 검사와 단일 파일 복원을 실행한다.
4. NAS 전체 장애를 가정해 백업 디스크가 다른 PC에서 읽히는지 확인한다.

처음엔 10GbE 스위치부터 사면 빨라질 거라 생각하기 쉽다. 실제로는 케이블 규격, PC NIC(Network Interface Card, 네트워크 카드), SMB 권한, 백업 계정이 하나라도 잘못되면 속도와 안전성 모두 놓친다. RS6426xs+를 홈랩에 넣는다면 링크 속도 확인보다 계정 분리와 복원 테스트를 먼저 끝내는 편이 결과가 좋다.

### 짧은 점검 요약

- DSM 7.4와 RS6426xs+ 지원 여부를 Synology Download Center에서 확인한다.
- NAS·PC·스위치의 링크 속도를 각각 확인한다.
- 관리·서버·IoT 네트워크를 가능하면 VLAN으로 나눈다.
- 관리자 계정으로 SMB를 연결하지 않는다.
- Hyper Backup 파일 복원까지 실제로 실행한다.
