*이 그림에서 볼 부분은 데이터 디스크와 운영체제가 올라간 부트 장치를 따로 보고, 고장 때 되돌릴 경로까지 비용으로 계산해야 한다는 점이다.*

TrueNAS 25.10을 파일 공유와 백업 중심으로 쓰는 1~2인 홈서버라면 부트 SSD 1개와 최신 설정 백업이 비용 대비 합리적이다. 원격 운영이나 VM·앱 중단이 손실로 이어지면 같은 용량의 SSD 2개 미러가 유리하다. 부트 미러는 데이터 풀과 별도라서 사진·문서 백업을 대신하지 않는다.

## TrueNAS 25.10이 요구하는 부트 장치

TrueNAS 공식 25.10 문서는 16GB SSD 부트 장치를 제시하고 USB 플래시 드라이브는 권장하지 않는다. 설치 단계에서 여러 장치를 고르면 부트 미러를 만들 수 있고, 부트 풀이 고장 나면 새 장치에 재설치한 뒤 설정을 복원한다.

| 구성 | 고장 시 동작 | 잘 맞는 환경 | 빠뜨리기 쉬운 비용 |
|---|---|---|---|
| SSD 1개 + 설정 백업 | 새 SSD에 재설치 후 설정·풀 가져오기 | 개인 파일, 주 1회 점검 가능 | 예비 SSD, 재설치 시간 |
| SSD 2개 미러 | 한 장치가 고장 나도 부팅 지속 | 원격 홈서버, 여러 앱·VM | SSD 1개 추가, 같은 용량 조건 |
| USB 플래시 1개 | 장치 수명·인식 문제 뒤 복원 | 임시 설치·테스트 | 장애 가능성, 교체 작업 |

미러의 두 번째 장치는 기존 장치 이상 용량이어야 한다. 같은 128GB라도 실제 크기가 다를 수 있어 같은 모델이 안전하다. USB보다 SATA·SAS·NVMe SSD를 우선한다.

## 구매하지 않아도 되는 경우와 사야 하는 경우

가상 사례로 4베이 서버에 HDD 데이터 풀, Docker 앱 3개, 주 사용자 2명을 둔다고 하자. 데이터 풀과 설정 파일이 별도 백업되고 장애 때 현장에 갈 수 있다면 SSD 1개로 시작해도 된다. 필요한 것은 다음 복원 목록이다.

```text
[ ] TrueNAS 설치 ISO와 현재 버전 기록
[ ] 최근 설정 파일 + secret seed 보관
[ ] 데이터 풀 암호화 키와 복구 암호 보관
[ ] 풀 구성과 공유 폴더 목록 기록
[ ] 새 SSD 1개 또는 호환 가능한 예비 장치
[ ] 다른 PC에서 설정 파일을 읽을 수 있는지 확인
```

무인 원격 서버나 여러 VM이라면 미러의 목적은 저장공간이 아니라 복구 작업을 미루는 것이다. 한 장치 고장 뒤에도 서비스가 계속될 수 있지만, 교체와 상태 점검은 필요하다. 미러만 믿으면 두 장치 동시 고장과 호스트 자체 고장에 취약하다.

## 총비용은 SSD 가격보다 중단 비용으로 계산한다

아래는 특정 판매 가격이 아닌 판단용 가상 계산이다. 2026년 10월 27일 실제 구매가는 용량·인터페이스·판매처를 다시 확인해야 한다.

| 항목 | 단일 SSD | 부트 미러 |
|---|---:|---:|
| 부트 SSD | 1개 | 2개 |
| 설정 백업 저장 위치 | 기존 PC·외장 디스크 | 기존 PC·외장 디스크 |
| 장애 시 예상 작업 | 재설치·복원 | 고장 장치 교체·리실버 |
| 운영 중단 가정 | 1~3시간 | 점검 시간 중심 |
| 구매하지 않아도 되는 조건 | 현장 접근 가능, 예비 SSD 보유 | 해당 없음 |

`두 번째 SSD 비용 < 예상 중단 시간 × 시간당 손실 + 출장·복구 비용`이면 미러가 맞다. 중단 비용이 작고 복원 가능한 서비스라면 두 번째 SSD보다 예비 SSD와 복원 리허설이 낫다.

## 복원은 파일을 내려받는 것으로 끝나지 않는다

TrueNAS 25.10에서는 설정을 내려받을 때 secret seed를 함께 보관하는 것이 권장된다. 새 장치에 설치하고 설정을 올린 뒤 네트워크를 확인하고 기존 풀을 가져온다. 암호화 풀은 키나 복구 암호가 없으면 열 수 없다.

실제 장비에서 복원을 수행하지 않았다면 성공했다고 가정하지 말고, 테스트 장치에서 다음을 확인한다.

1. 설정 파일과 secret seed를 다른 장치에 보관한다.
2. 설치 후 고정 IP·DNS, 공유 권한과 앱 경로를 확인한다.
3. 기존 풀을 가져온 뒤 SMB 파일·Docker 앱·스냅샷을 각각 읽는다.
4. 복원 시간과 누락된 수동 설정을 기록한다.

부트 미러는 백업의 상위호환이 아니다. 데이터·설정 백업과 현장 복원이 가능한 소규모 서버는 SSD 1개로 시작해도 된다. 원격 홈랩은 내부 SSD 2개 미러를 고르고, 어느 쪽이든 복원 절차를 한 번 확인해야 한다.
